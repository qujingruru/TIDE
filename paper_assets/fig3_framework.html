A Design Framework

Information-Theoretic Measurement of Thinking in Dialogue

Three layers, from construct to metric, from text to number, from number to valid inference
Layer 1

Construct-to-metric mapping

What to measure, with which metric
  • Fluency → lexical entropy, MATTR
  • Originality → surprisal, self-referential novelty
  • Flexibility → semantic distance to self
  • Engagement → semantic distance to partner
  • Process dynamics → trajectory features
→
Layer 2

Operationalization methods

How to compute the metrics for dialogue
  • Condition every metric on the dialogue history
  • Reference every measurement to the speaker’s own baseline
  • Aggregate from single turns into process-level readouts
→
Layer 3

Design principles

How to use and validate the measurement
  • Analyse at the dimension level
  • Measure self-referentially
  • Interpret semantic distance as engagement
  • Validate by manipulation and external outcomes
Implemented as the open-source pipeline TIDE — Turn-level Information-theoretic Dialogue Evaluation
